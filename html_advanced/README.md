# html_advanced

## About

This project implements a full landing page from a Figma design, built with pure semantic HTML — no CSS or styling yet. The goal at this stage is to get the document structure and tag hierarchy correct: header, banner, quote, video list, membership, FAQ, and footer sections, all nested exactly as the design calls for.

Styling is added in a later project; for now the page will look plain, which is expected.

![Landing page wireframe](https://via.placeholder.com/800x450?text=GymPro+Landing+Page+Wireframe)

## Structure

- `index.html` — the full single-page layout:
  - `<header>` with a clickable logo and a 3-link nav block
  - `<main>` containing, in order:
    - a banner section (heading, text, CTA button, and a 4-item features block)
    - a quote section (member photo + quote)
    - a videos section (4 video cards, each with an author block and a star rating)
    - a membership section (4 plan cards + CTA button)
    - an FAQ section (2 rows of 2 question/answer items)
  - `<footer>` with a logo, social links, and a copyright line
