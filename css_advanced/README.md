# css_advanced

## About

This project adds the visual styling to the Smile School landing page built in `html_advanced`, following the Figma design: header, banner, instructors, quote, videos, membership, FAQ, and footer, all styled with a purple accent theme.

![Styled landing page preview](https://via.placeholder.com/800x450?text=Smile+School+Styled+Preview)

## Structure

- `index.html` — the same semantic structure from `html_advanced`, with classes added for styling hooks
- `styles.css` — all visual styling: colors, spacing, layout, typography
